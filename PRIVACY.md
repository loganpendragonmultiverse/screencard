# Privacy policy

Effective date: August 3, 2026

ScreenCard has no developer-operated server, account system, analytics, advertising, telemetry, or
tracking. It does not collect, sell, rent, or receive user data.

The application stores a local watchlist, research notes, expiring TMDB response cache, and—only if
the user explicitly chooses—TMDB API Read Access Token in browser storage. The token otherwise uses
session storage. A browser request containing that token is sent directly to TMDB when ScreenCard
needs data. Images load from TMDB's image service.

Markdown and JSON exports are generated locally and downloaded by the browser. ScreenCard does not
upload those files. Exports can contain research notes and TMDB data; the user controls where they
are shared afterward.

Clearing site data removes ScreenCard's local state. Removing the remembered token from the Token
dialog clears both its local and session copies.

TMDB processes API requests under its own privacy policy and terms. ScreenCard is not endorsed or
certified by TMDB.
